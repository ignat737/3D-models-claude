# 3D-модели юнитов

Low-poly модели юнитов для стратегии в духе Diplomacy is Not an Option. Каждая модель — один
GLB со скелетом и клипами анимации, **один меш и один материал** (цвета — крошечная текстура-палитра),
то есть один draw call на юнит: сотни юнитов на экране не упираются в процессор.

## Клипы

У всех боевых юнитов одни и те же имена клипов, поэтому код игры для них один; у рабочих свой набор (см. ниже). `idle`, `run` и `attack`
идут по кругу, `death` играется один раз, и юнит остаётся лежать. Исключения: у лошади `idle`, `run`, `attack`, `runAttack`, `death` (`attack` — на месте,
`runAttack` — на скаку); у волка свой набор движений — зверь, а не пехотинец: `attack` — присел, прыгнул и укусил, 0,8 с, `death` — взвизгнул, подогнул передние лапы и завалился на правый бок, 1,2 с; у мечника есть ещё клипы верхом (см. «Всадник на лошади»); у катапульты и орочьей баллисты имена те же, но это машины (см. «Осадные машины»); у гоблина на волке клипы волка, а гоблин едет вместе с костью `body` и играет поверх них своё:

| Клип | Волк | Гоблин |
|---|---|---|
| `idle` | стоит, дышит | осматривается: голова ±35°, корпус поворачивается за ней, остриё дротика покачивается |
| `run` | бег прыжками | пригнулся к шее, корпус гасит подпрыгивание, голова смотрит вперёд |
| `attack` | присел, прыжок, укус, 0,8 с | откидывается при приседании, на прыжке колет дротиком вперёд над головой волка |
| `throw` | стоит настороже, 1,5 с | замах с поворотом корпуса, бросок: дротик исчезает в момент выпуска, рука тянется к связке за спиной за новым |
| `runThrow` | бежит (два шага галопа), 1,5 с | тот же бросок на скаку |
| `death` | заваливается на правый бок, 1,2 с | перелетает через спину волка и лежит рядом |

`throw` и `runThrow` — только в `goblin-wolf-rider.glb`, у `wolf.glb` их нет.

| Клип | Мечник | Лучник | Копейщик | Орк | Гоблин | Тролль |
|---|---|---|---|---|---|---|
| `idle` | меч остриём вниз, щит у бедра | лук опущен у левого бока | копьё стоит упором в землю | топор стоит обухом в землю у правого бока | дротик стоит в руке, гоблин озирается | дубина лежит головой на земле, тяжёлое дыхание |
| `run` | щит перед собой, меч поднят | лук качается в левой руке | копьё наискось вперёд, двумя руками | топор наискось поперёк груди, двумя руками | дротик наискось вперёд, быстрая перебежка | дубина двумя руками поперёк груди, тяжёлая поступь |
| `attack` | замах над правым плечом и косой удар с шагом, 0,9 с | стрела из колчана, натяжение, выстрел, 1,5 с | отвод и укол с выпадом, 1,0 с | две руки над головой, топор отведён назад, быстрый рубящий удар вперёд и вниз с выпадом, 1,1 с | замах и бросок: дротик исчезает в момент выпуска из руки, новый появляется из связки за спиной, 1,5 с | дубина двумя руками над головой и удар сверху с выпадом, 1,4 с |
| `death` | падает на спину | падает на спину, лук вдоль тела | падает на спину, копьё вдоль тела | падает на спину, топор вдоль тела | падает на спину, дротик вдоль тела | падает на спину, дубина вдоль тела |

### Рабочие

У `worker.glb` и `orc-worker.glb` пять клипов: `idle`, `run`, `chop`, `mine` идут по кругу, `death` играется один раз, и рабочий остаётся лежать. Боя (`attack`) у них нет. Клипы одинаковые у человека и орка (орк играет те же позы на своём, более крупном скелете). Две кости-инструмента, `axe` и `pick`, висят на торсе. Пока инструмент не нужен, он неподвижно стоит на спине (топор слева, кирка справа, V за плечами) и едет вместе с телом в любом клипе и при переходах; в `chop` топор, в `mine` кирка каждый кадр ставится в правую кисть, второй остаётся на спине.

| Клип | Что делает | Длительность |
|---|---|---|
| `idle` | стоит с пустыми руками, оба инструмента на спине, медленно осматривается, чуть сутулится | 2,6 с |
| `run` | бежит с согнутыми руками, инструменты на спине | 0,64 с |
| `chop` | горизонтальный взмах: топор лежит плашмя на уровне груди, замах вправо с поворотом корпуса, рез слева направо поперёк ствола перед рабочим (около 0,9 м), возврат; кирка на спине | 1,0 с |
| `mine` | кирка над головой, глубокий выпад и удар остриём вниз-вперёд на высоте бедра (камень перед рабочим), отдача и снова замах; топор на спине | 1,2 с |
| `death` | колени подгибаются, падает на спину, руки раскинуты, инструменты на спине (играть с `loop: false`) | 1,3 с |

Моменты удара: `chop` — на 0,5 цикла (0,5 с), `mine` — на 0,52 цикла (0,62 с); под них можно ставить звук и частицы. Ступни в `chop` и `mine` всегда на земле, обе руки держат древко (проверяют тесты).

```js
clips.play('chop');        // рубка
clips.play('mine');        // добыча камня
clips.play('death', { loop: false });
```

## Всадник на лошади

Всадник — отдельная модель (мечник), он садится на кость `saddle` лошади и едет вместе с ней.
У каждого клипа лошади есть парный клип мечника **той же длины и с тем же числом кадров**:
запускать их надо вместе.

| Лошадь | Мечник верхом | Что происходит |
|---|---|---|
| `idle` | `ride` | стоят, дышат |
| `run` | `rideRun` | галоп, всадник наклонён вперёд, колени пружинят |
| `attack` | `rideAttack` | удар с места, 0,9 с: лошадь приподнимается на дыбы и бьёт копытом, плечо, локоть и меч повторяют пешую атаку; корпус всадника удерживает удар рядом с шеей лошади |
| `runAttack` | `rideRunAttack` | тот же удар на скаку, 1,28 с (два шага галопа) |
| `death` | `rideDeath` | 1,8 с, один раз: у лошади подгибаются передние ноги, она заваливается на правый бок, всадника перебрасывает через спину (в сторону −X), он лежит на земле рядом |

Масштаб и направление задаются лошади, всаднику — только клипы.

```js
const horse = Model3D.build(await Model3D.load('assets/models/horse.glb', view.scene), view.scene, { name: 'horse' });
const rider = Model3D.build(await Model3D.load('assets/models/swordsman.glb', view.scene), view.scene, { name: 'rider' });
World3D.addObject(view, horse, 'actor');
World3D.addObject(view, rider, 'actor');
horse.scaling.setAll(0.25);
Model3D.mount(rider, horse, 'saddle');              // false — у лошади нет такой кости
const play = (name, riderName, opts) => {           // оба клипа сразу
  Model3D.clips(horse).play(name, opts);
  Model3D.clips(rider).play(riderName, opts);
};
play('run', 'rideRun');
play('runAttack', 'rideRunAttack');
play('death', 'rideDeath', { loop: false });        // после смерти остаются лежать
Model3D.dismount(rider);                            // слезть: остаётся на месте в мире
```

Перед `Model3D.dispose` лошади всадника снимают (`dismount`), иначе он удалится вместе с ней.
Снимок: `node tools/unit-preview.mjs horse --rider=swordsman` (для лежащих — `--gap=100`).

### Всадник одним файлом

`mounted-swordsman.glb` — то же самое, но без `mount`: лошадь и мечник собраны генератором в одну
модель (`tools/units/mounted-swordsman.mjs`, сам ничего не рисует, берёт `horse.mjs` и
`swordsman.mjs`). Один меш и один материал — один draw call на всадника вместо двух, один

## Осадные машины

Катапульта людей и баллиста орков — машины без расчёта с теми же четырьмя клипами, что у бойцов, поэтому код игры для них тот же; у таранов `attack` — удар стволом, у осадных башен людей и орков `attack` — это опускание подъёмного моста (оружия у неё нет). Общая часть генератора — `tools/units/siege-kit.mjs`: точное касание земли (восьмигранные колёса катятся по граням), крен рамы на угол без колеса, обломки, которые падают и ложатся на землю.

### Катапульта

`catapult.glb` — осадная машина без расчёта, те же четыре клипа, что у бойцов, поэтому код игры для неё тот же. Камень — отдельная кость `stone` на раме: в `idle` и `run` он лежит в ложке, в `attack` вылетает и прячется масштабом 0,02 (не 0), в `death` падает на землю.

| Клип | Что делает | Длительность |
|---|---|---|
| `idle` | взведена и заряжена: рычаг оттянут назад к вороту, камень в ложке, рычаг чуть поскрипывает, вымпел колышется | 2,4 с |
| `run` | едет вперёд: колёса делают **ровно один оборот за цикл** (2π·0,42 = 2,64 м), восьмигранные колёса катятся по граням — рама подпрыгивает 8 раз за оборот, рычаг дребезжит, вымпел полощется | 1,6 с |
| `attack` | выстрел: рычаг срывается (0,17 с), бьёт в подушку упорной балки (0,33 с) — камень вылетает вперёд-вверх под 40°, 20 м/с; раму подбрасывает задом, рычаг отскакивает и успокаивается; ворот в шесть рывков опускает рычаг обратно (0,9–2,5 с), в ложке появляется новый камень (2,5–2,7 с) | 3,0 с |
| `death` | разрушение: от удара переднее правое колесо отлетает и ложится плашмя, рама заваливается на этот угол, рычаг бьёт в подушку и ломается — верх с ложкой падает слева, камень выкатывается вперёд, упорная балка перекашивается, мантелет падает лицом вниз, вымпел — на землю за машиной; обломки лежат на земле (играть с `loop: false`) | 2,2 с |

Момент выстрела — **0,33 с** от начала `attack` (`RELEASE_TIME` в `tools/units/catapult.mjs`): тогда игре спавнить свой снаряд и звук. Камень модели виден ещё 0,23 с (около 4 м полёта) и прячется. Чтобы колёса не скользили, скорость клипа `run` подгоняется под скорость движения: при `speed: 1` — 1,65 м/с.

```js
const cat = Model3D.build(await Model3D.load('assets/models/catapult.glb', view.scene), view.scene, { name: 'catapult' });
World3D.addObject(view, cat, 'actor');
cat.scaling.setAll(0.25);
const clips = Model3D.clips(cat);
clips.play('run', { speed: metersPerSecond / 1.65 });   // колёса катятся без проскальзывания
clips.play('attack');                                    // выстрел на 0,33 с каждого цикла (3 с)
clips.play('death', { loop: false });                    // остаются обломки
```

Цена: 900 треугольников, 13 костей, 11 цветов. Снимок: `node tools/unit-preview.mjs catapult`.

### Осадная башня

`siege-tower.glb` — осадная башня людей на четырёх колёсах. Оружия у неё нет, поэтому `attack` — **опускание подъёмного моста**: те же четыре клипа, что у остальных машин, и код игры тот же. В `idle`, `run` и в начале `attack` мост поднят и стоит щитом спереди.

| Клип | Что делает | Длительность |
|---|---|---|
| `idle` | стоит: башня поскрипывает, верхняя площадка слегка покачивается, мост чуть качается на петле, вымпел колышется | 2,4 с |
| `run` | едет вперёд: колёса делают **ровно один оборот за цикл** (2π·0,45 = 2,83 м), восьмигранные колёса катятся по граням — рама подпрыгивает 8 раз за оборот, башня раскачивается, площадка отстаёт от неё, вымпел полощется | 2,0 с |
| `attack` | опускание моста: мост отпускают (0,29 с), он падает вперёд по нарастающей и ложится горизонтально на стену (**1,1 с**, настилом вверх), подпрыгивает и успокаивается; башню слегка встряхивает, площадка дрожит; мост лежит до 2,2 с, затем его медленно поднимают воротом (2,2–3,3 с), и цикл начинается с поднятого моста | 3,6 с |
| `death` | разрушение: переднее правое колесо отлетает и ложится плашмя, рама заваливается на этот угол (около 17°), боевая площадка с зубцами дрожит, срывается и падает вверх дном слева, подъёмный мост падает вперёд лицом вверх, левая обшивка срывается и ложится вправо, вымпел с шестом — назад на землю; обломки лежат на земле (играть с `loop: false`) | 2,6 с |

Момент, когда мост ложится на стену, — **1,1 с** от начала `attack` (`LAND_TIME` в `tools/units/siege-tower.mjs`): тогда игре пускать отряд на стену и звук. Скорость клипа `run` подгоняется под скорость движения: при `speed: 1` — 1,41 м/с.

### Тараны

`battering-ram.glb` (люди) и `orc-battering-ram.glb` (орки) — навес на колёсах с тяжёлым стволом, подвешенным под коньком крыши. Те же четыре клипа, что у остальных машин, поэтому код игры для них тот же; кости, клипы и разрушение общие (`tools/units/ram-kit.mjs`), в файлах юнитов — только облик. Экипажа нет.

Ствол (кость `log`) не вращается, а **сдвигается по дуге**: два подвеса (`hangF`, `hangR`) поворачиваются каждый вокруг своей верхней точки, ствол каждый кадр ставится под ними, как на параллельных подвесах. Так ствол остаётся горизонтальным и не задирает задний конец в стойки. Подвесы не висят в воздухе: каждая пара крутится на железной оси (кость `body`), которую держит под балкой стержень между двумя подвесами. В `death` ствол дополнительно наклоняется носом вниз вокруг нижнего конца заднего подвеса (`log.rotation`) и падает на переднюю поперечину, состоящую из двух половин (кости `beamL`, `beamR`) с муфтой: они разлетаются от удара.

| Клип | Что делает | Длительность |
|---|---|---|
| `idle` | стоит: рама поскрипывает, ствол чуть покачивается на подвесах, вымпел колышется | 2,4 с |
| `run` | едет вперёд: колёса делают **ровно один оборот за цикл** (люди 2π·0,40 = 2,51 м, орки 2π·0,46 = 2,89 м), восьмигранные колёса катятся по граням — рама подпрыгивает 8 раз за оборот, ствол раскачивается на кочках | 1,6 с |
| `attack` | удар: короткая пауза, ствол медленно отводят назад (0,24–1,08 с), он поскрипывает в верхней точке, затем быстро летит вперёд и **бьёт в стену на 1,5 с** (ход ствола около 1 м: люди 0,6 м назад и 0,5 м вперёд от покоя); раму отбрасывает назад и встряхивает, ствол отскакивает и плавно возвращается на место (1,5–2,4 с) | 2,4 с |
| `death` | разрушение: переднее правое колесо отлетает и ложится плашмя, рама заваливается на этот угол, крыша дрожит и срывается — летит вправо и падает набок **по часовой стрелке (при виде спереди)**. Затем ствол **обрывается у переднего подвеса** (сам подвес остаётся на оси под балкой и свободно раскачивается, пока не повиснет отвесно), а на заднем подвесе ствол остаётся: он поворачивается вокруг его нижнего конца и **падает на переднюю поперечину**. Поперечина составная (две половины, скреплённые железной муфтой): от удара муфта и перекладина **разделяются, половины разлетаются в стороны и падают на землю**. После этого ствол роняет нос до земли, чуть отскакивает и замирает, **касаясь земли только передним концом** (человеческий — нос под углом около 28°, орочий — около 18°), задняя часть висит на заднем подвесе. Вымпел или знамя с шестом падают назад; обломки лежат на земле (играть с `loop: false`) | 2,4 с |

Момент удара — **1,5 с** от начала `attack` (`HIT_TIME` в `tools/units/battering-ram.mjs` и `orc-battering-ram.mjs`): тогда игре наносить урон и пускать звук. Скорость клипа `run` подгоняется под скорость движения: при `speed: 1` — 1,57 м/с у людей и 1,81 м/с у орков.

```js
const ram = Model3D.build(await Model3D.load('assets/models/battering-ram.glb', view.scene), view.scene, { name: 'battering-ram' });
World3D.addObject(view, ram, 'actor');
ram.scaling.setAll(0.25);
const clips = Model3D.clips(ram);
clips.play(moving ? 'run' : 'idle', { speed: moving ? metersPerSecond / 1.57 : 1 });
clips.play('attack');                                    // удар в стену на 1,5 с каждого цикла (2,4 с)
clips.play('death', { loop: false });                    // остаются обломки
```

Цена: человеческий — 944 треугольника (лимит 1000), орочий — 1268 (лимит поднят до 1400 через `maxTriangles`), по 13 костей; цвета: 7 у человеческого, 10 у орочьего. Снимки: `node tools/unit-preview.mjs battering-ram`, `node tools/unit-preview.mjs orc-battering-ram`.

## В ArcEngine

Скопировать файл в `assets/models/` (путь к ассету в коде — литералом `'assets/…'`, иначе сборщик
его не увидит) и расставить во вкладке Objects редактора или из кода:

```js
const model = await Model3D.load('assets/models/swordsman.glb', view.scene);
const unit = Model3D.build(model, view.scene, { name: 'swordsman' });
World3D.addObject(view, unit, 'actor');
unit.scaling.setAll(0.25);                          // как персонаж набора
unit.position.set(x, terrain.heightAt(x, y), y);
const clips = Model3D.clips(unit);
clips.play(moving ? 'run' : 'idle');
clips.play('attack');
clips.play('death', { loop: false });
```

Цвет команды — тексели `team` и `teamDark` палитры (`tools/units/<юнит>.mjs`).

## Как меняются модели

Модели генерируются кодом, руками файлы не правятся:

```
node tools/make-units.mjs              # пересобрать все модели
node tools/make-units.mjs swordsman    # только мечника
node tools/make-units.mjs --check      # проверить, что файлы совпадают с генератором
node tools/unit-preview.mjs swordsman          # 3D-models-units/previews/swordsman.png — снимок в сцене игры
node tools/unit-preview.mjs swordsman --squad  # 3D-models-units/previews/swordsman-squad.png — отряд с камеры RTS
```

Юнит описан в `tools/units/<имя>.mjs` (кости, детали из коробок и усечённых конусов, палитра,
позы клипов); общее тело (кости, лицо, руки и ноги, бег, падение) — `tools/units/humanoid.mjs`,
сборщик GLB — `tools/unit-glb.mjs`. Новый юнит — новый файл в `tools/units/` и строка в `UNITS`
в `tools/make-units.mjs`.
