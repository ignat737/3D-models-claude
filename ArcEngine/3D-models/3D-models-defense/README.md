# 3D-модели укреплений

Low-poly модели оборонительных сооружений в том же стиле, что и юниты и здания: один GLB, **один меш и
один материал** (цвета — крошечная текстура-палитра, 4×4), один draw call. Статичные: ни скелета,
ни клипов.

Башня стоит на линии стены: центр квадрата на оси частокола, сегмент прикладывается торцом к любой из четырёх её граней — один и тот же файл для прямой стены, угла и развилки. Между осями соседних башен — 3 + 10·N м. Ворота ставятся вместо сегмента, на ту же линию: брёвна у них кончаются ровно на ±5 м. Площадка для стрелков на высоте 3,6 м; лучник на ней ростом 1,7 м виден по грудь над парапетом.

Метры, +Y вверх, внешняя сторона (остриями и ровным рядом брёвен) смотрит в +Z, сегмент идёт вдоль X
от −5 до +5. Начало координат — на земле в центре сегмента. Брёвна кончаются ровно на ±5 м, шаг
брёвен и узор высот повторяются, поэтому сегменты стыкуются торец в торец: ставить через 10 м вдоль
X (угол — поворотом вокруг Y). Цвет команды — тексели `team` и `teamDark`, как у юнитов и зданий.

## В ArcEngine

Как здания (см. [`../3D-models-buildings/README.md`](../3D-models-buildings/README.md)): файл в
`assets/models/`, `Model3D.load` + `Model3D.build` + `World3D.addObject(view, mesh, 'prop')`. Длинная
стена — десятки одинаковых сегментов: `World3D.addInstances(view, mesh, 'prop', items)`.

## Как меняются модели

Модели генерируются кодом, руками файлы не правятся. Описание — `tools/defense/palisade-segment.mjs`
(поле `folder: '3D-models-defense'`; каменные — `stone-*.mjs` и общий `stone-common.mjs`: палитра, кладка рядами, боевой ход с зубцами, знамёна; срубные — `timber-*.mjs` и общий `timber-common.mjs`: венцы из брёвен, дощатый боевой ход), сборщик — `tools/make-buildings.mjs`:

```
node tools/make-buildings.mjs palisade-segment         # пересобрать (также palisade-tower, palisade-gate, palisade-gate-open, stone-wall-segment, stone-tower, stone-gate, stone-gate-open, timber-wall-segment, timber-tower, timber-gate, timber-gate-open)
node tools/make-buildings.mjs --check                  # файлы совпадают с генератором?
node tools/unit-preview.mjs palisade-segment           # previews/palisade-segment.png
node tools/unit-preview.mjs palisade-segment --with=spearman --pose=20   # с юнитом рядом (масштаб)
```
